# xWalk sound resources

These WAV files provide the horn and engine-start effects used by `xWalkSelfDrive`. Their root-level
`xWalkSounds` location follows the workspace naming convention. The runtime uses `../xWalkSounds/...` paths
when the application is started from `xWalkCLI`.

The files were copied without modification from the SunFounder `picar-x` repository at commit
`d912972d3a209685a3e575dcf0dff4c49bae300e`. The upstream project declares GNU GPL version 2 or any later
