# xWalk audio resources

`xWalkAudioResources` owns the sound-effect and background-music assets distributed
with the SunFounder PiCar-X examples. Consumers use the explicit `sounds/` and
`music/` child directories so an asset's role remains visible while provenance,
installation, and maintenance stay under one resource boundary.

The files were copied without modification from the SunFounder `picar-x`
repository at commit `d912972d3a209685a3e575dcf0dff4c49bae300e`.
